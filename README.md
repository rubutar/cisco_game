# cisco_game

A 2D pixel-art game built with Unity 6 (6000.6.9f1), URP 2D renderer.

## Getting started

1. Install Unity **6000.6.9f1** via Unity Hub.
2. In Unity Hub, choose **Add > Add project from disk** and select this folder.
3. Open `Assets/Scenes/SampleScene.unity`.

## Layout

- `Assets/Art/Sprites`, `Assets/Art/Tilesets` - textures imported here get pixel-art settings automatically (point filter, uncompressed, 16 PPU)
- `Assets/Scripts` - gameplay code
- `Assets/Prefabs`, `Assets/Audio`, `Assets/Scenes`
